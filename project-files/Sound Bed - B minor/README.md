# Sound Bed

Five editable MIDI parts: 707 kick, clap, hats, Operator triangle bass, mellow Electric chords. No lead melody.

Drop an instrument on PLAY HERE and try a short phrase over the loop. B minor notes: B C# D E F# G A.

The MIDI and score are saved here. Live set saving is handled in Ableton; this folder is not an .als save or an audio bounce.
