# Justin - taste profile (2026-09-03, his words)

Makes Electronic Dance Music. Grew up in 2001. Loves vocal chops, UK Garage, house. Used to really love tech house.

Artists: Fisher, John Summit, Bicep, Fred again.., Sammy Virji.
Sound design inspiration above all: Space Laces.

## What that implies for defaults (Claude's reading, correct me)

- Home tempos: house 122-126, tech house 126-130, UKG / 2-step 130-136. Trap at 140 is a visitor.
- Drums: swung 16ths, shuffle, skippy 2-step kicks, open-hat offbeats, claps layered on snares. Not boom-bap.
- Bass: sub + mid split, syncopated 8ths with gaps (UKG), rolling saw/FM (tech house), 808 slides only in trap.
- Vocal chops everywhere: Simpler slice-to-MIDI, formant shifts, pitched one-shots as hooks. Sammy Virji / Fred again style.
- Sound design: Space Laces = aggressive, surgical, modulation-heavy, resampled. Tools on this machine that reach there: Surge XT, Wavetable, Roar, Saturn 2, Pro-Q 4, PaulXStretch, Neutone Morpho, resampling chains.
- Keys: piano/organ stabs (garage), warm chords (Bicep), filtered pads under vocal loops (Fred again).

## Verdict context so far

- trap-7 keep, boombap-3 bin, house-5 keep with default sounds binned.
- The boombap bin is genre, not craft. Weight it accordingly: don't conclude "swing bad" from it.
